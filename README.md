# Video → Game 原型

这是一个浏览器端 MVP：把参考视频放入页面后，显示本地视频预览，提取基础玩法指纹，并生成一个可操作的 3D 球体合并跑酷原型。

## 运行

在此目录启动静态服务器，然后打开 `http://127.0.0.1:4173/`：

```powershell
node server.mjs
```

## 当前复刻范围

- 三轨道前进
- 左右换道
- 2、4、8、16…球体合并升级
- 尖刺与断桥
- 进度、分数、失败与重开
- 手机左右滑动

参考视频只在浏览器本地预览，当前版本不上传文件，也没有把任意视频自动变成任意游戏。真正的 1:1 复刻还需要逐帧标注对象、碰撞规则、输入方式、胜负条件和关卡节奏。
